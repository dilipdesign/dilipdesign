01 / Context

One platform.
Multiple complex
workflows.

The Sports Event Management platform supports a wide range of interconnected event operations, including Event Management, Venue Management, Team Management, Roster Management, Entry Management, Finance and Administration.

Each module has its own business rules and workflows, while many interface patterns are shared across the product.

My work spans product UX and the design system. I identify recurring patterns across modules and turn them into reusable components, interaction rules and documented guidelines.

Alongside design, my experience with HTML, CSS, SCSS and Bootstrap gives me an implementation-aware perspective when creating components and collaborating with developers.

02 / Challenge

Creating consistency
across a complex
product.

The challenge was not simply to create consistent-looking screens. The goal was to establish reusable patterns with clear behavior and documentation that could work across multiple product modules.

01

Multiple modules

Different product areas required their own workflows while sharing common navigation, actions, tables, forms and interaction patterns.

02

Reusable patterns

Repeated patterns needed to be identified, consolidated and turned into reusable components rather than redesigned independently.

03

Design-to-code alignment

Components needed to be practical for implementation and easy to communicate with developers during handoff and collaboration.

System Thinking

Beyond the
component.

A design system is not only a collection of Figma components. It also needs clear rules for when a pattern should be used, how it behaves, and how it connects with the rest of the product.

My documentation work therefore covers both the visual component and the product behavior around it.

Examples include table action headers, left navigation drawers, module tabs and sections, dialogs, icons, breadcrumbs and destination links.

08 / Reflection

Designing beyond
individual screens.

Product thinking + system thinking + implementation awareness.

Working on a complex enterprise product has reinforced that good UX is not only about solving the immediate screen-level problem. It is also about creating patterns that can work consistently across the wider product.

Building the design system has given me the opportunity to move from designing individual experiences to thinking about reusable components, shared behavior, documentation and governance.

My background in HTML, CSS, SCSS and Bootstrap adds another perspective: understanding how design decisions can be translated into practical frontend implementation and communicating those decisions effectively with developers.
